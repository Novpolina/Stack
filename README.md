# Defensive Stack

Реализация динамического стека на C++ с диагностикой повреждения данных.

## Возможности

- автоматическое изменение ёмкости;
- canary-значения для контроля границ;
- хеширование данных и структуры;
- проверка инвариантов и подробный диагностический дамп.

## Запуск

```bash
make
./stk
```
